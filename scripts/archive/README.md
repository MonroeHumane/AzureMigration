# Archived one-off QBO remediation scripts

Each script here was a single-use fix for one specific transaction or account
in QuickBooks Online, applied once during the Sep 2026 books audit. They're
kept for the audit trail (what was changed, why, and how) — not meant to be
run again. See `memory/qbo_full_audit_2024_2026.md` for the full narrative.

The `deposit_5820_*` scripts are an iteration trail on the same issue —
`qbo_apply_deposit_5820_final_fix.py` is the one that actually ran; the other
three were superseded attempts kept for the record.
